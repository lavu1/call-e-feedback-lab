# Focused build plan

## Completed locally

- Reviewed the official event rules and CALL-E direct-API documentation.
- Implemented a dependency-free Node.js harness for doctor, preview, guarded create
  and read-only status/event collection.
- Added loopback-only mock tests and generated test evidence.
- Added automatic credential, email and E.164 redaction with a mandatory manual
  review warning.
- Compared the official README SDK version statement with public npm metadata and
  prepared one confirmed documentation finding.
- Consolidated confirmed evidence, observations, suggestions and blockers into one
  reviewable report.

## Remaining authorized live session: estimated 3-5 hours

| Time | Work |
|---|---|
| 0-45 min | Confirm account, key, Devpost registration, survey access, recipient consent and destination support. |
| 45-120 min | Run one consented setup-to-call-to-result role-play and capture the same Call ID through terminal status. |
| 120-180 min | Exercise an ambiguous answer and a naturally occurring interruption only if each call is separately authorized. |
| 180-240 min | Reproduce the strongest account-dependent observation and sanitize evidence. |
| 240-300 min | Update the single report and perform a privacy and claim review. |

This is an estimate for future substantive testing, not elapsed time already claimed.
Do not manufacture failure scenarios by calling an unconsenting person or repeatedly
dialing a recipient.

## Definition of finished

The feedback entry is ready only when account access and eligibility are confirmed,
the real test evidence supports every CALL-E runtime claim, and the entrant has
reviewed the one survey response. Form submission remains an external action and is
not authorized by this repository work.
